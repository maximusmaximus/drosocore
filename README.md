# DROSOCORE

**A hydrogen fusion tokamak maintained and extended by fruit flies.**

DROSOCORE is a compact tokamak whose entire operations crew is *Drosophila melanogaster* — welders, cryogenics techs, plasma physicists, coil installers, and one janitor with a broom.

This repository is the public face of the project. The live isometric simulator is the product.
